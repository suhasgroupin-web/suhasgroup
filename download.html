Download & Install SUHAS-MAX

SUHAS-MAX is the official social, professional and business community app from SUHAS GROUP. Use it on Android phones, iPhone, tablets and computers.

Open SUHAS-MAX

Install on Android (Chrome / Samsung Internet)

  1. Open the official website using Google Chrome.
  2. Tap the Chrome menu (⋮).
  3. Choose Install app or Add to Home screen, if shown.
  4. Confirm the installation. The SUHAS-MAX icon will appear on your home screen.

Install on iPhone or iPad

  1. Open the official website in Safari.
  2. Tap Share, then choose Add to Home Screen.
  3. Tap Add.

Install on a computer (Microsoft Edge / Chrome)

Open the website in a supported browser such as Chrome or Edge, then use the browser's Install app option when available.

Is an APK file available?

SUHAS-MAX is currently provided as an installable Progressive Web App (PWA). An official standalone Android APK file is not currently published on this website. Avoid unofficial APK downloads claiming to be SUHAS-MAX. Use the official website and the browser's install option.
